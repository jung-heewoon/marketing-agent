# 유튜브 댓글 에이전트

지정 채널의 최신 영상을 불러오고, 로컬 모델이 시청자 말투의 댓글 초안을 만든 뒤, 크롬 프로필에서 한 글자씩 입력해 게시하는 대시보드입니다. 웹에 올리지 않고 이 컴퓨터에서만 실행합니다.

## 준비

1. Python 3.12
2. 설치된 Chrome
3. 로컬 모델. 초안을 만들기 전에 바탕화면의 `run-iq2_xs.bat` 을 실행합니다. 주소는 `http://127.0.0.1:8080` 입니다. Gemini로 바꾸려면 `config.yaml`의 `llm.provider`를 `gemini`로 두고 환경변수 `GEMINI_API_KEY`를 넣습니다.

```bat
cd marketing-agent
python -m venv .venv
.venv\Scripts\python -m pip install -r requirements.txt
```

가상환경은 이미 만들어 두었습니다. 다시 설치할 때만 위 명령을 쓰면 됩니다.

## 실행

1. `run-iq2_xs.bat` 실행
2. `marketing-agent\run.bat` 실행
3. 브라우저에서 http://127.0.0.1:7860 열기

## 처음 한 번만 할 일

1. 대시보드에서 프로필 `유튜브1`을 고르고 `선택한 프로필 로그인`을 누릅니다.
2. 열린 크롬에서 구글 계정으로 직접 로그인하고, 유튜브 언어가 한국어인지 확인한 뒤 창을 모두 닫습니다. 이 로그인은 설치된 크롬을 그대로 엽니다. 자동화 창으로 열면 구글이 안전하지 않은 브라우저라며 로그인을 막습니다.
3. 시연용 영상을 올렸다면 `config.yaml`의 `test_video_ids`에 영상 ID 11자를 넣습니다. 지정 채널이 아니어도 그 영상은 열리고 게시할 수 있습니다.

가점으로 유튜브2, 유튜브3도 같은 방식으로 로그인할 수 있습니다. `돌아가며 배정`은 성공한 게시 다음 프로필을 고릅니다.

## 쓰는 순서

1. `영상 불러오기` — 지정 채널 5개의 최신 영상이 썸네일, 제목, 채널, 날짜로 나옵니다.
2. 영상을 고르거나 링크를 직접 넣습니다. 링크는 채널을 확인해서 지정 채널과 테스트 영상이 아니면 막습니다. 고르는 순간 로컬 모델이 초안을 만듭니다.
3. 고민 한 줄과 댓글을 확인하고, 필요하면 고친 뒤 `댓글 달기`를 누릅니다.
4. 화면 상태가 `프로필 여는 중` → `입력 중` → `게시 완료 · 댓글 보기`로 바뀝니다. 실패하면 이유와 화면 캡처가 기록에 남습니다.

`뜨기 직전 찾기`는 최근 영상 중 조회수 1,000~5,000이면서 시간당 150 이상인 영상만 보여주고 초안까지만 만듭니다. 그 목록에서는 게시 버튼이 꺼집니다.

## 운영 규칙

코드에서 막습니다.

- 지정 채널 5개와 `test_video_ids`만 열기·게시
- 영상당 성공 댓글 1개. 계정을 가리지 않습니다
- 하루 성공 게시 10개. 기준은 한국 시간이고, 프로필을 합쳐 셉니다
- 댓글 40~120자. 운명원이 있고, 아직 안 본 호기심이 있어야 함. 연애사주나 인연사주는 덧붙여도 됨
- 링크, 해시태그, 한자, 운명원을 이미 써 본 가짜 후기 금지
- 운명원을 영상 문장의 주어로 쓰면 게시하지 않음
- 말투와 영상 속 말 언급은 초안을 고를 때 점수로 보고, 화면 경고로 남깁니다. 그 이유만으로 게시 버튼이 막히지는 않습니다.

YouTube Data API 키가 있으면 환경변수 `YOUTUBE_API_KEY`에 넣습니다. 없으면 공개 채널 피드와 자막으로 동작하고, 조회수는 영상 페이지 정보로 확인합니다.


## 만든 것

- Python, FastAPI, 브라우저 한 페이지
- 채널 목록은 유튜브 공개 RSS
- 자막은 [youtube-transcript-api](https://github.com/jdepoix/youtube-transcript-api)
- 인기 댓글은 API 키가 있으면 YouTube Data API, 없으면 [youtube-comment-downloader](https://github.com/egbertbouman/youtube-comment-downloader)
- 게시는 [Playwright](https://playwright.dev/)로 설치되어 있는 Chrome 프로필을 엽니다. 기본 프로필은 쓰지 않습니다.
- 초안은 Strata의 OpenAI 호환 API `POST /v1/chat/completions`

비밀값, 크롬 프로필, 화면 캡처, 데이터베이스는 Git에 넣지 않습니다.

## 제작 의도

평가용 페이지를 인터넷에 올리면 크롬 프로필을 열 수 없어서, 이 컴퓨터에서만 켜지는 세 칸 화면으로 만들었습니다. 처음 보는 사람이 1, 2, 3 순서만 따라가면 되게 버튼을 나눴습니다.

과제가 준 자료는 자막, 자막이 없으면 제목과 설명, 그리고 인기 댓글입니다. 여기에 [LiveWiki](https://livewiki.com/ko/)를 하나 더 붙였습니다. 유튜브 영상을 무료로 요약해 주는 사이트라, 전용 크롬 프로필로 그 요약을 받아 모델에 넘기는 자료에 넣습니다. 자막이 짧거나 없을 때도 영상이 어떤 연애 고민을 다루는지 모델이 먼저 알게 하려고 넣었습니다. 요약이 없어도 자막이 있으면 초안은 계속 만듭니다.

초안 모델은 Qwen의 Qwen3.8-Flash-Next입니다. 파라미터 규모는 180B급이라 보통은 서버에서 돌리는 크기이고, Flash 구조라 매 토큰에 전문가를 일부만 켭니다. 그 가중치를 llama.cpp의 IQ2_XS로 약 2비트까지 줄여, 이 컴퓨터에서 로컬로 엽니다. 주소는 `http://127.0.0.1:8080` 입니다. 설정에서 Gemini로 바꿀 수 있습니다.

문장은 한 번에 광고처럼 쓰지 않고 세 단계로 나눴습니다. 먼저 모델이 그 영상에서 고민 한 줄, 영상 속 말, 시청자 페르소나만 정리합니다. 이 단계에는 운명원을 넣지 않습니다. 그다음 그 영상의 자막이나 LiveWiki 요약, 그 영상 댓글만 보고 방금 본 사람처럼 반응을 씁니다. 다른 채널에서 모아 둔 댓글은 넣지 않고, 보여 준 문장을 그대로 베낀 줄은 고르지 않습니다. 마지막에 그 댓글은 그대로 두고, 같은 말투로 이어서 그 사람 인연을 운명원에서 본다던 말만 따로 씁니다. 가본다는 후기 대신 본다, 해볼까로 잇고, 앞 문장의 단어를 그대로 넣지 않습니다. 연애사주나 인연사주는 그 옆에 덧붙여도 됩니다. 코드가 두 문장을 이어 붙입니다. 120자가 넘으면 운명원 바로 앞의 말만 남기고, 말 중간은 자르지 않습니다. 보면 답이 나온다는 후기와, 운명원을 사람처럼 주어로 쓴 문장은 뺍니다.

후보가 여러 개면 글자 수, 영상 속 말, 말투로 점수를 매깁니다. 여기에 Laya를 더했습니다. 다국어 문장 판별 모델이라, 사람 댓글처럼 들리는지, 읽은 사람이 운명원 사주가 궁금해지는지, 영상 내용과 맞는지를 보고 가산점을 줍니다. Laya를 불러오지 못하면 그 점수 없이 규칙만으로 고릅니다. 필수 규칙을 통과한 문장이 없으면 실패한 문장은 보여 주지 않고 처음부터 최대 두 번 다시 만듭니다. 그래도 통과하지 못하면 그 초안을 경고와 함께 보여 줍니다. 이 컴퓨터의 모델은 한 번에 요청 하나만 처리하므로 초안이 나가는 동안 다시 누르지 못하게 했습니다.

게시 전에 코드가 막는 것은 글자 수, 운명원, 링크, 해시태그, 한자, 지어낸 후기, 허용 채널, 영상당 성공 댓글 1개, 하루 성공 10개입니다. 하루 기준은 한국 시간이고 프로필을 합쳐 셉니다. 말투와 영상 속 말 언급은 후보를 고를 때 점수로 보고, 화면 경고로 남깁니다. 그 이유만으로 게시 버튼이 막히지는 않습니다.

게시는 평소 쓰는 크롬이 아니라 프로필 폴더를 지정해 엽니다. 유튜브1은 필수이고, 유튜브2·유튜브3과 돌아가며 배정은 가점으로 넣었습니다. 링크를 직접 넣으면 채널을 확인해 지정 채널과 테스트 영상이 아니면 막습니다. 한 글자씩 타이핑하는 모습이 시연 영상에 보여야 해서 입력 속도를 느리게 두었고, 내 댓글이 목록에 보여야 성공으로 기록합니다. 실패하면 이유와 화면 캡처가 기록에 남습니다. 기록은 어느 영상인지, 어느 프로필인지, 무슨 댓글인지, 성공인지 실패인지를 시간순으로 보여 줍니다. 조회수 1,000~5,000이면서 시간당 150 이상인 영상은 뜨기 직전으로만 보여주고, 그 목록에서는 게시하지 않습니다.
